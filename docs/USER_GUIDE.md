# 用户指南

## 文章

在文章管理页可以拖入 `.md` 文件，或打开已有文章编辑标题、摘要、标签、日期、封面和正文。导入后先确认文件名和封面预览，再保存。

正文中的本地图片会在发布前进入图库处理流程。建议使用 PNG、JPEG 或 WebP，避免在 Markdown 中保留 `C:\Users\...` 等本机绝对路径。

## 城市足迹

添加城市后，客户端会根据内置城市表补充经纬度。可以选择“居住”或“旅行”，填写评价，并配置旅行专题文章入口。

## 友链

每条友链包含名称、地址、描述和头像。头像为空时，博客会尝试使用站点图标，并在失败时显示文字占位。

## 项目

项目页用于展示开源仓库、技术栈、解决的问题、交付物、演示地址和关联文章。项目封面为空时会显示代码占位图标。

## 快照与发布

1. 修改内容后创建快照。
2. 在发布控制中选择当前数据或某个快照。
3. 观察动态进度条中的连接、上传、构建和部署阶段。
4. 发布完成后访问博客检查首页、文章页和图片。
5. 无用快照可以在版本管理页删除。

## 故障排查

- `127.0.0.1 拒绝连接`：Flask 服务未启动。
- `SSH 私钥不可用`：检查 `WONELOG_SERVER_KEY` 路径和文件权限。
- 图片裂开：检查图片是否已上传、Markdown 是否仍引用本机路径。
- 发布构建失败：登录服务器，在源码目录执行 `npm install && npm run build` 查看完整日志。
